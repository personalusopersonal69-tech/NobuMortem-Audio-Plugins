# NOBU MORTEM — DARK AUDIO COLLECTION

Free, lightweight VST3 audio tools for FL Studio on Windows 10/11 x64.

## Collection

- **GPKISM / KAYA Vocal Suite** — dark, elegant vocal tone shaping, formant/resonance coloration, dynamics, controlled harmonic saturation, ambience; Clean and Intense performance modes.
- **Guttural Forge** — industrial/electro-metal inspired guttural enhancement that keeps the dry vocal blended in to preserve the user's voice.
- **Vocal Tuner Pro** — pitch detection and correction with user-selected key/scale, correction speed, and natural/creative modes.

## Visual identity

Visual Kei gothic, aristocratic/dark romantic influence: black surfaces, silver accents, deep violet highlights, restrained ornament, readable controls, and subtle meters. Influences are aesthetic references only; no artist voice cloning or copied artwork.

## Technical goals

- VST3, 64-bit, Windows x64, FL Studio compatibility.
- Efficient native DSP; no cloud service, no neural model running locally.
- Mono/stereo support, adjustable input/output, dry/wet where appropriate, bypass.
- Avoid clipping: input/output metering and safe output gain.
- Build and validation via GitHub Actions where feasible.
- Every release must be labeled experimental until built and tested in a DAW.

## Development status

Repository scaffolding only. No plugin binary is available yet.

## First project

Start with GPKISM Vocal Suite. The initial milestone is a working, lightweight VST3 with basic processing and a GUI. Later milestones add refined formant shifting, preset automation, and validation. The sonic target is a style-inspired character, not an exact replica of any singer.

## User environment

- Windows 10, 64-bit
- 8 GB RAM
- FL Studio
- User prefers an easy install/download workflow and does not want to manually program.
